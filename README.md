# Nsight Compute profiles

Native reports generated by the course PR monitor, grouped by PR author's GitHub login and profiling date:

```text
<login>/TaskNN_YYYYMMDD/pr123_5dcbb19_1.ncu
<login>/TaskNN_YYYYMMDD/pr123_5dcbb19_2.ncu
```

The filename contains the PR number, seven-character tested commit SHA and one-based profiling-run number. Dates use the worker's local date. `.ncu` files contain the native Nsight Compute report format (normally named `.ncu-rep`); rename the extension if your UI's file picker requires it.

Reports are requested with a relative path, for example `ncu --metrics gpu__time_duration.sum -c 1 --export profile_report`. The PR bot links to the exact report-storage commit, so later uploads do not alter earlier downloads. Upload failures are shown in the diagnostic log and do not change the ordinary test verdict.

This is an orphan data branch. Assignment source branches are not modified.
